# 📚 Gestion de cours

## Description
Ce projet est une application Java de gestion de cours.
Elle permet d’ajouter, afficher, rechercher et supprimer des cours.
La recherche des cours se fait par enseignant.
L’interface graphique est réalisée avec Swing et l’accès aux données se fait via JDBC.

## Fonctionnalités
- Ajout d’un cours
- Affichage des cours
- Recherche des cours par enseignant
- Suppression d’un cours
- Vérification des champs obligatoires

## Technologies utilisées
- Java
- Swing
- JDBC
- MySQL

## Structure du projet
- `model` : classes métiers
- `dao` : accès à la base de données
- `ui` : interface graphique
- `util` : outils et connexion JDBC
- `database` : script SQL
